# ✦ Maison Lune

An editorial-inspired luxury fashion e-commerce frontend built with React and Tailwind CSS.

Minimal, elegant, and fully responsive — focused on a modern high-fashion shopping experience.

---

## ✦ Features

- Editorial-inspired luxury UI
- Responsive storefront design
- Modern product & collection layouts
- Clean and minimal aesthetic

---

## ✦ Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
